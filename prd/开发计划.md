


## 开发计划
---

### Phase1 - 数据模拟与设计
1. 目标：确定需要的数据
2. 数据汇总：
    1. 数据资产 -  Medical Synea CSV tables
    2. 数据标准 - 57个初始标准 - json
    3. Business Entity  - 10个初始Business Entity - AI generate
    4. PII - 常见PII - AI generate

### Phase 2 - 利用模拟数据搭建和验证基础UI和后端
1. 目标功能：
    1. 实现用户登录功能
    2. 实现基础UI页面以及相关功能
      1. Search bar
      2. 数据资产概览
      3. 数据质量page
      4. 数据标准page
      5. PII page
      6. Business Entity page
2. 微服务
    1. 数据Profile - reuse old code
    2. 数据分类 (PII, Standards, ...) - reuse old code (缺失的部分写死）
    3. 数据质量 - reuse old code
3. 前端UI实现
4. 后端服务，存储，ORM等实现

### Phase 3 - 相关微服务开发和改善
1. Data Profiling Refine
2. Data Classification Refine - 接入LLM
    1. RAG + Hybrid Ranking
    2. 算法：通过LLM + RAG + BM25实现更精确的Data type, Standards, Entity, PII 匹配
3. Data Quality Engine Refine 
    1. 根据DC, Profiling结果改善DQ计算
    2. 根据DC结果实现DQ Rule推荐
4. 验证测试新数据导入计算流程 - 确保各个微服务的正确性

### Phase 4 - NL接口Agent开发
1. 实现对数据资产的大模型自然语言接口，right pane
2. 对用户prompt or query进行关键词提取
3. 数据资产知识库构建 - Meta Data等Vector Store
4. LLM + RAG + Verification 进行数据资产信息汇总
5. 设计计算模块 - NL2SQL agent进行
