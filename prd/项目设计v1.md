

## 项目描述
---

- 定位: 数据治理平台，支持数据资产管理，数据质量评估，数据分类引擎，以及基于LLM的自然语言查询接口
- 功能：
  - 对Entity, Standards, 元数据, PII，DQ管理与展示
  - NL Agent 自然语言数据资产查询接口
  - 连接数据，生成Data Profile
  - 连接数据，生成Data Classification结果 (Entity, Standards, Type, PII)
  - 连接数据，推荐DQ Rule, 生成DQ Score
- LLM
  - Smart Data Classification Engine is powered by LLM
  - Smart Search - user can search all relative data assets powered by LLM
  - NL Interface [Agent] - in right pane 
    - Users ask questions about current data assets, LLM gives the answers
    - Users want to directly compute some quantities LLM agents use NL2SQL to do it


### 项目基础架构设计


#### 后端
- Backend
    - Data Connectors 
        - CSV in V1 - add more connectors MySQL, postgres in future
        - Example data - Medical Syneac csv files
    - Storage - SQLite - replace Postgres in future version
        - Data Standards
        - Business Entity
        - Meta Data - Profile, standards, domain, dq, ....
    - Backend service 
        - Fastapi
        - sqalchemy orm
        - FTS - full searching - switch to elastic search in future

- LLM 技术栈
    - RAG - QDrant, Langchain, Langraph
    - Agent - Langraph
    - LLM - Google Gemini flash

- Micro Service Modules
    - Data Profiling
    - DQ engine
    - Data classification engine


#### 前端

- UI 设计 - React - reuse components from OpenMetaData
  - Login Page - login Platform
  - Main Page
    - Middle Search Bar
    - Under search bar, glance at current data assets (mysql -200, postgres 20)
  - Data Asset Browsing Page
    - Show existing assets
      - DB Type -> DB -> Tables -> Columns
      - DB information - table list
      - Table information - tab1 - column list, tab2 - row view
      - Column information
        - Profile - stats
        - DQ
        - Matched entity, standards, PII, domains
    - Add new data assets (e.g. Upload an csv)
      - Automatically processing meta data, classification and DQ score (using micro service)
      - After processing, it shows detailed information in asset browsing page
  - DQ Page
    - User can select a db, table, column
    - Show overall DQ of selected, default show DQ of all user data assets
  - Data Standards Page
    - 功能：显示, 管理平台所有已有的 data standards
    - 纵向列出所有standards, 分页显示，
    - 每个standards一行，显示名称，描述和相关标记（类型，subject area, business domain）
    - 点击standard, 显示其详细信息 - name, description, alias, type, subject area, domain, 标准规则 - validation rules
  - Business Entity Page
    - 功能：显示, 管理平台所有已有的Business Entity
    - 纵向列出所有Entity, 分页显示，
    - 每个Entity一行，显示名称，描述和相关标记（类型，subject area, business domain）
  - PII Page
    - Management PII
